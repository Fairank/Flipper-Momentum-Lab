# 蓝牙远程操作 Flipper

连接成功后，在 iPhone 的“设备”页进入“远程操作 Flipper”。手机接收设备屏幕帧，显示真实的 128 × 64 画面，并通过六个屏幕按钮发送方向、确认、返回事件。菜单导航、打开应用和应用内选择都由 Flipper 本机执行；它仍是实际读卡、收发、GPIO 和扩展模块工作的设备。

本功能使用此仓库锁定的 `assets/protobuf/gui.proto` 中 `StartScreenStreamRequest`、`ScreenFrame`、`SendInputEventRequest` 和 `StopScreenStreamRequest`，对应 `applications/services/rpc/rpc_gui.c` 的现有处理器，不需要为每个原生应用新增蓝牙命令。按键默认发送 `PRESS → SHORT → RELEASE`；明确打开“下一键发送长按事件”时发送 `PRESS → LONG → RELEASE`，不持续按住或自动重复。离开页面停止屏幕流，手机在远程操作期间切到后台则断开蓝牙会话，防止设备继续保留按键或屏幕流。协议帧与显示缓冲区都设有大小限制。

| 功能 | 手机端方式 | 必须满足的条件 |
| --- | --- | --- |
| 桌面、设置、文件、已安装的本机应用 | 远程画面加六键操作 | 当前固件允许该画面接收远程输入；设备保持连接 |
| Flipper Lab 中文入口 | 从远程画面打开 | 设备安装本仓库固件和相应应用 |
| 红外、Sub-GHz、NFC、RFID、iButton | 在远程画面操作本机应用；资料库还可导入/上传支持的记录，红外有单独的已校验按钮发送 | Flipper 的相应硬件须靠近目标；当地法规、设备兼容性和应用自身限制仍适用 |
| GPIO、外接模块 | 从远程画面操作对应本机应用 | 需要正确接线和兼容模块；本项目尚未为型号未知的扩展板添加专用驱动 |

远程画面提供的是本机 UI 操作通道。它不会让 iPhone 的蓝牙天线直接代替 Flipper 的 NFC、射频、红外或 GPIO 硬件，也不会自动把设备上的每个功能变成单独的手机原生页面。部分流程可能要求在 Flipper 机身确认、接触目标、插线、插 SD 卡或使用外接模块；这些情况应在真机逐项记录。屏幕流和按键目前尚未经 iPhone 17 Pro Max 与 Flipper Zero 真机验收，不能把源码完成或模拟器构建视为“全部功能已跑通”。

验收时至少记录：首次配对、断线重连、首页/设置/Flipper Lab/文件页画面一致性、六键顺序、应用中的短按与长按需求、离开远程页和切到后台时设备能否释放屏幕流，以及红外/NFC/Sub-GHz/RFID/iButton/GPIO 在连接状态下各自的实际结果。
