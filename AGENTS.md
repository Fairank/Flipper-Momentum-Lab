# Project instructions for Fairank/Flipper-Momentum-Lab

## Owner authorization (2026-10-23)

The repository owner explicitly revoked the inherited prohibition on AI contributions.
AI-assisted source edits, tests, protocol updates and USB firmware installation are authorized
in this fork. This supersedes the former upstream AGENTS.md policy for this repository.

- Do not invoke Claude or require its setup.
- Preserve the existing merged functionality, English device UI and saved mute setting.
- Review upstream changes and preserve their attribution and licenses.
- Validate changes with relevant regressions and a complete firmware/application build.
- Before installation, back up settings, verify the connected device and upgrade package,
  then verify the installed firmware, application resources and preserved settings.
- Keep device backups, unique identifiers and credentials local and out of Git history.
