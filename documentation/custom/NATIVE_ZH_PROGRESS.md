# 原生中文界面进度

更新日期：2026-09-27。分支 `codex/iphone-zh-architecture`。本轮从中文帮助入口扩展到原生应用、系统设置和 GUI 文字显示。**仍不是全系统重写或全界面中文验收完成**。

## 已完成的源码改动

- `applications/main` 与 `applications/settings` 共 227 个 C 文件、1,039 处字符串翻译；另有桌面/加载器提示和菜单显示别名。涵盖 NFC、Sub-GHz、红外、低频 RFID、iButton、GPIO、文件管理、Momentum 设置及系统设置中的多项菜单、确认和错误提示。
- 翻译审计逐文件比较除字符串外的 C 词法标记，并比较 printf 格式符，未发现控制代码或格式符被翻译改动。射频驱动没有重写。
- `locale_ui_label()` 只转换显示名称。存储设置名称同时被启动参数、快捷键与收藏使用，因此底层名称保留原值；主菜单与存储子菜单通过中文别名显示。
- `canvas.c` 在选定字体缺字时回退到中文子集；已有字体的 ASCII 和自带中文字符保留。文字测量、绘制和对齐使用相同字形，绘制后恢复选定字体。
- 修复多字节文字截断、滚动、自动换行和 TextBox 行高；中文采用至少 12 像素行距，保留格式控制符。纯 ASCII 文本保留原排版路径，并修复行数组上限。
- 字库由源码中的汉字自动收集并检查：当前 679 字形（95 ASCII + 584 非 ASCII），17,048 字节。来源为文泉驿 12 像素点阵字体，许可见 `applications/main/lab/FONT_LICENSE.md`。CI 检查生成结果与源码一致。
- 正常固件携带中文子集；恢复升级器仍使用原有字体，以保持旧固件的 128 KiB 加载限制。

## 验证与预览

完整固件、字库和 C 桌面回归的实际运行记录以 [VALIDATION.md](VALIDATION.md) 为准。测试覆盖中文回退、宽度/对齐、字体恢复、滚动、窄框、换行和 TextBox 行数；生成字库逐字形检查真实像素范围。

`python scripts/render_native_zh_preview.py --output-dir <目录>` 可生成 NFC、红外、Sub-GHz 和低频 RFID 的代表菜单预览。标签取自应用源码，字形取自实际字库，按原生 submenu 的行高/基线排列。它是**源码布局预览，不运行固件，不是真机截图**，不模拟动态菜单、条件分支、自定义主题或操作结果。

## 仍需处理

- 部分动态拼接信息、协议插件详情、公共服务提示、启动/恢复界面与第三方外部应用仍有英文；技术协议名、单位、路径、调试日志和应用标识不作为普通文案翻译。
- 字库只包含源码用字，不支持任意中文输入，也没有新增中文输入法或运行时语言切换。
- 128×64 真机上的全部页面、主题字体、弹窗、方向切换、快捷键和收藏还未逐项验收；自动测试与代表预览不能证明所有页面均无截断。
- 固件代码通过编译不代表改动已刷入用户设备。本轮没有连接、刷写或操作用户硬件。
