## 手机 GPS 与网络处理端

此前只有固件侧 GPS/网络接口，本轮补上 iPhone 处理端和“设备 → 手机能力共享”页面：

- 定位与网络分别由用户开启，蓝牙就绪前不能启用，每次新会话默认关闭；App 进入后台或设备断开会停止共享。定位只请求“使用 App 时”权限。
- 定位支持单次请求及 1–10 次/秒的流式请求；实际频率取决于 iOS 定位服务。检查坐标有效性和新鲜度，蓝牙慢时只保留最新位置；单次请求 30 秒超时。iPhone 不提供卫星数量，Flipper 页面显示 `--`。
- 网络支持 HTTP(S)、TCP、UDP 与 WebSocket 的应用请求。连接数量、响应体、数据帧与排队均有上限；慢速蓝牙会反向限制网络接收，取消会结束对应会话。HTTP 数据传输完成前持续占用并发名额。
- 固件把调用应用的 `/data/...` 解析成实际 SD 目录；手机只接受 `/ext/apps_data/<应用>/...`，单个文件/HTTP 正文最多 2 MiB，写入后读回校验。取消或断开可能留下不完整文件，需重新下载。
- 系统 TLS 和默认 ATS 保持生效；普通 HTTP/未加密 WebSocket 是否可用由系统决定。本轮没有全局放开不加密连接。这是应用请求转发，不是手机系统热点或透明 VPN。
- 手机 RPC 对新增 protobuf 内容严格解码；普通控制请求与共享数据按完整帧排队，不能把两帧字节交错发送。连接确认排在该连接的数据之前，重复 ID 不会误关已有连接。

新增可直接安装的工具入口：`apps/Tools/gps_rpc.fap` 显示手机定位；`apps/Tools/example_network.fap` 需按确定键才发送一次 `https://example.com/` 请求，并把响应保存在自身应用的 SD 目录。手机“功能”页只有实际发现这些安装文件后才会显示入口，中文显示名不会改写启动路径。操作步骤见 [手机能力共享使用说明](PHONE_COMPANION_GUIDE.zh-CN.md)。

## 中文字库与固件空间

原来主固件距无线栈起点仅余 944 字节。本轮把常规中文绘制改成 SD 资源与有界缓存：

| 项目 | 当前实现 |
| --- | --- |
| 常规资源 | `/ext/locale/zh_cn.glyphs`，925,216 字节，包含原文泉驿字体的 7,097 个 CJK/全角字形；随升级包资源安装 |
| 无卡基础显示 | 固件内保留 223 字形的启动/恢复相关子集，SD 错误和基础菜单仍可显示；其他缺失字形显示方框 |
| 缓存 | 96 个字形项、64 项请求队列，约 13.5 KiB 缓存结构及 2 KiB 工作线程栈；绘制线程不读 SD。需要真机验证长期 RAM/栈余量 |
| 资源校验 | 检查文件大小、版本头及记录格式；插拔卡触发重试，损坏记录不被当成可用字形 |
| 恢复升级器 | 仍使用独立 135 字形子集，不依赖 SD 字库启动 |
| 本地包 | 主固件 871,528 字节，到 `0x080D7000` 还余 9,112 字节；恢复升级器 123,857 字节，低于 131,072 字节限制 |
| 已下载核验的云端包 | `41fd31347` 对应合并检出 `0f6dff61`：主固件 871,504 字节，保留区前余 9,136 字节；恢复升级器 123,829 字节 |

本地包由修改后的工作树构建，文件名含旧 HEAD `344bf038`，不是该旧提交的干净产物。最终云端包以 [验证记录](VALIDATION.md) 中的提交、运行编号及摘要为准。保留原打包地址检查，`.free_flash` 仍不能被解释为无线栈之前的全部可用空间。扩充字库把部分代价移到了 SD 访问与 RAM，并非免费增加硬件容量。

源码预览仍使用自动生成的 782 字形子集作参考；此头文件不再作为常规固件的完整中文字库链接。7,097 字形也不等于全部 Unicode，不提供中文输入法或运行时语言切换。

## 第三方应用补充与差异表

继续保留 Momentum 的固定应用子模块，按固定 [all-the-plugins 提交](https://github.com/xMasterX/all-the-plugins/tree/eb87c158c7dbc930d74c3ae3ccb6b59cad5fc833) 增加第二批十个应用：手机 GPS、棋钟、红外暂停计时器、Mandelbrot 分形、反应测试、Brainfuck 解释器、骰子/硬币、三门问题、陶笛、赛车。加上前轮十个普通工具，共导入二十个；手机联网测试由已有固件示例提升为正式工具。

本轮适配中文标题、常规菜单及多处 128×64 排版；陶笛的 19 个曲名改为中文，每页两首以容纳中文行高。修复反应测试向字符串常量写入、重复等待，以及三门问题长按事件落在超时分支中的上游缺陷。保留来源、作者和许可证；原始文件摘要见 `applications/union/UPSTREAM.json`。82 张导入图片经仓库构建工具规范为单色/无元数据，转换前后的实际单色像素逐个比较一致。**部分应用内嵌按键图片与间接字符串仍为英文**，未对游戏实际操作做真机验收。

增加按入口函数、显示名称与应用本地源码多重匹配的审计器，避免把改名误算成缺失功能。421 个参考条目的结果为：

| 结果 | 条目数 | 解释 |
| --- | ---: | --- |
| 应用本地源码相同 | 36 | 不是整个固件、资源、依赖或运行行为相同的证明 |

本轮 UI 扫描覆盖 48 种 GUI 函数的 9,886 个文本参数：1,141 个含中文、4,478 个待审查直接文本、3,766 个动态参数、501 个中性符号/数字。其中外部应用有 4,433 个待审查直接文本。**这不是中文覆盖率**：自定义绘制、图片文字、宏、字符串表及运行时拼接还需单独追踪。
