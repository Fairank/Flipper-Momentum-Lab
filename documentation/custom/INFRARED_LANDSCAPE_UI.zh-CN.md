# 红外横屏界面

本次更新现有 `Infrared` 应用，采用 Flipper 的黑白像素风格、横屏大按钮和方向键选择。设备界面继续使用英文；本说明解释各入口和操作。

## 入口

| 页面文字 | 用途 |
| --- | --- |
| By brand | 直接打开新增型号库，依次选择设备类别、品牌、遥控器型号。 |
| Universal | 按电视、空调等类别轮询通用红外码；包含原有全部九类和外部码库入口。 |
| Learn | 使用原遥控器逐键学习。 |
| Saved | 打开原有及自己保存的遥控器。 |
| Output | 选择内置或 GPIO 红外输出，保留原有供电设置。 |
| Debug RX | 查看接收的信号；仅在系统已开启 Debug 时可进入。 |

首页和通用类别每页六个按钮。已保存遥控器每页四个较大的按钮，顶部显示型号和页码，底部显示当前操作提示。长名称会滚动显示。

方向键左右按顺序移动，上下移动到同列的上一行或下一行。超过一页时自动翻页，末尾可循环返回；最后一行只有一个按钮时不会选中空位。

## 遥控

已保存遥控器的普通按键保持“按住 OK 发送、松手停止”。发送期间不能切换到其他按钮；返回会先停止当前发送。`+ Add` 和 `Edit` 分别保留学习新按键与编辑功能，只在短按 OK 时打开。

`Vol + / Vol -` 表示音量增减，`CH + / CH -` 表示频道增减。空调通用面板显示 `Off`（关机）、`Dry`（除湿）、`Cool max / Cool low`（原高/低制冷记录）和 `Heat max / Heat low`（原高/低制热记录）。这些是现有码库的记录名称，不承诺任意温度或风速调节。

通用面板选中功能后短按 OK 开始尝试码库。进度页提供暂停与停止；暂停后可逐条选择、发送一条或保存。外部通用码库同样使用横屏按钮，取消不会触发发送。

## 更新范围

更换的是 SD 卡上的 `apps/Infrared/infrared.fap`。学习、重命名、删除、移动按键、原有通用红外库、手机 RPC 控制和底层收发逻辑保留。新增型号库仍包含 1648 份遥控器文件，其中电视 397 份、空调 158 份。

修复了手机 RPC 成功载入遥控器后，设备端仍停留在等待图标的问题。现在显示已载入的型号，并保持可以接收后续遥控操作的就绪状态；失败载入仍向手机返回错误，不显示成已就绪。

安装前保留旧应用和设置备份，应用先上传到独立临时文件，校验后再替换。资源清单仅更新该应用一条记录；主固件、无线栈、配对信息、雷达应用和静音设置按原值核对。

自动测试覆盖网格边界、翻页、显示名称、按键释放、取消、回调重入和锁定入口。真实屏幕检查与完整构建结果记录在同目录 `validation/INFRARED_LANDSCAPE_UI_20261102.json`；测试界面不等于已经验证所有家电响应。
