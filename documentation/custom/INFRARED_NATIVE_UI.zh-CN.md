# 红外原生界面

用户否决了横屏卡片布局，本次恢复此项目原有的 Flipper 界面。设备继续使用英文，操作说明使用中文。

## 页面和操作

- 首页恢复原生列表：`Universal Remotes`、`Learn New Remote`、`Saved Remotes`、`GPIO Settings`、`Debug RX`。
- 通用遥控恢复原来的图标按钮，保留电视、投影仪、音响、空调、灯具、风扇、蓝光/DVD、显示器、数字标牌九类，以及 `Load from Library File` 入口。
- 遥控面板和已保存遥控器恢复原本的竖屏布局，方向键随画面方向旋转。等待和通用码库进度页也与原版布局一致。
- 已保存遥控器仍按住 OK 发送、松开停止；`+` 用于学习新按键，`Edit` 用于编辑。重命名、删除、移动和学习流程保留。
- 通用遥控可暂停、逐条选择、保存和停止，功能与既有融合版一致。

## 新增内容仍然保留

型号库路径为 `Infrared → Saved Remotes → More_Remotes`。新增的 1648 份家电遥控器文件、其中 397 份电视和 158 份空调遥控器文件不受界面恢复影响。文件数量不等于新协议数量，也不代表已逐台验证兼容。

保留手机 RPC 载入成功后显示型号的修复。载入成功后保持就绪，失败仍向手机返回错误。遥控器退出时显式停止红外发送的保护也保留。

## 更新及验证范围

本次只更换 SD 卡上的红外应用和对应资源清单条目，不安装主固件或无线栈。保留现有融合功能、配对、桌面、雷达应用和静音设置，并留存本机备份和设备上的旧应用回退副本。

验证记录见 `validation/INFRARED_NATIVE_UI_20261102.json`。自动测试、完整固件/应用构建及设备页面检查不能替代所有家电响应测试；本轮界面检查不进行红外发射，USB 上的 RPC 验证也不等于蓝牙传输验收。
