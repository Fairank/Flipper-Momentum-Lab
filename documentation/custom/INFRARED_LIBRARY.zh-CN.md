# 电视、空调与家电红外补充库

本次扩充可直接从现有红外应用打开的 `.ir` 遥控器数据。设备已有 14 种结构化红外协议与 RAW 波形支持；本次没有增加协议解码器。补充库放在 SD 的 `/ext/infrared/More_Remotes`，不需要重刷主固件或蓝牙栈。

## 怎么找

打开 `Infrared → Saved Remotes → More_Remotes`，依次选设备类别、品牌和遥控器文件，再选择所需按键。也可以从 Archive 打开相应 `.ir` 文件。

| --- | --- | ---: |
| TVs | 电视 | 397 |
| ACs | 空调 | 158 |
| Fans | 风扇 | 155 |
| LED_Lighting | 红外灯具 | 168 |
| Projectors | 投影仪 | 125 |
| Audio_and_Video_Receivers | 音视频功放 | 103 |
| SoundBars | 回音壁 | 105 |
| Speakers | 音箱 | 69 |
| 其他 20 类 | 空气净化器、机顶盒、播放器、加湿器等 | 368 |

共 28 类、1648 份遥控器文件、31854 条按键记录，其中 25249 条为结构化协议码，6605 条为 RAW 波形。这是文件与记录数量，不等于经过实物验证的型号数量，也不代表所有记录彼此独立。

常见品牌示例：`GREE` 是格力，`Midea` 是美的，`Haier` 是海尔，`Hisense` 是海信，`Daikin` 是大金，`Mitsubishi` 是三菱，`Panasonic` 是松下。电视目录还包括 TCL、三星、索尼、LG、小米等。品牌目录里的文件可能对应遥控器型号或设备型号，选文件时应同时核对型号和按键用途。

## 空调使用边界

空调遥控常在一次发射中携带开关、模式、温度、风速等整套状态。这里的 `Cool_24` 等按键重放贡献者采集的状态；不能把一组固定波形当成任意温度、模式均可调的通用温控器。源文件里的状态说明保留为注释，可以在电脑或文件编辑器中查看。

同品牌也可能使用不同协议或状态格式。无法匹配时，可用原遥控器逐键学习，保存为自己的 `.ir` 文件。仅使用蓝牙或其他无线电控制的设备，不会因为增加红外文件就具备相应无线连接能力。

本次保留原有 `infrared/assets/tv.ir` 与 `ac.ir` 通用轮询库。当前界面恢复 Flipper 原生样式，从 `Saved Remotes` 进入 `More_Remotes` 型号库。型号库不会自动出现在通用面板的按钮中。没有将新的、更小的上游通用库覆盖本机融合库。

45 条超出固件结构化字段位宽的记录未导入；2 份文件不符合已保存遥控器格式，整份排除。自动转换目录 `_Converted_` 不在本次家电导入范围，避免把转换成功当成兼容性证明。
